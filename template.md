## 表格 - 用户信息列表

### 布局

表格布局描述

| 名称     | 字段   | 宽度 | 筛选 | 类型             | 固定 | 扩展                 |
| -------- | ------ | ---- | ---- | ---------------- | ---- | -------------------- |
| 操作     |        | 80   |      | action:编辑,删除 | Y    |                      |
| 用户姓名 | text_1 | 150  | Y    |                  | Y    |                      |
| 用户账号 | text_2 | 120  | Y    |                  | Y    |                      |
| 状态     | text_3 |      | Y    | dic:xb           |      |                      |
| 金额     | text_4 |      |      |                  |      | amount, align: right |
| 部门     | text_5 | 200  |      |                  |      | type=tag             |
| 资金信息 |        |      |      | multi:现金账户   |      |                      |
| 余额     | djJe   | 120  |      |                  |      | align: right         |
| 可用金额 | djKy   |      |      |                  |      | sum, decimal: 2      |

> **扩展** 列：逗号分隔多个值，每个值对应 GvTable `table-head` 列属性（Table-Column Attribute）：
>
> | 扩展值              | 含义                 | 生成的 GvTable 列属性                          |
> | ------------------- | -------------------- | ---------------------------------------------- |
> | `amount`            | 数值按千分位显示     | `align: 'right'` + `render` 内调 `amountFormat` |
> | `align: left/right` | 单元格内容对齐方式   | `align: 'left'` / `align: 'right'`             |
> | `type=tag`          | 单元格内容用 Tag 显示 | `type: 'tag'`                                  |
>
> 多个扩展可组合，如 `amount, align: right`。
>
> 「类型」列 `multi:<分组名>`（字段留空）= 多级表头分组起始行，其后连续带字段的行是子列，生成 `multiLabel` + `heads`；子列「扩展」支持 `align:` / `sum` / `decimal: N`。
