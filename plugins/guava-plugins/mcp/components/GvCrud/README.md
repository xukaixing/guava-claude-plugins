# GvCrud MCP

随 **guava-plugins** 分发。运行时不依赖 press / guava-ui 源码。

| 数据 | 来源 |
| --- | --- |
| 用法 / API / 示例 | 本目录 `usage.json` |
| 实现源 | `guava-ui packages/utils/gv.crud.ts` |

注册名：`gv-crud`

> **注**：`GvCrud` 不是 Vue 组件，而是 CRUD 工具函数集合。通过 `import { crud } from 'guava-ui'` 或 `import { crud } from '@/hook/service/useCrud'` 使用。
